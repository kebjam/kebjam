
# Text Summarization - NLP AS3 (2025)

Ce projet présente une application complète de **résumé de texte** (text summarization) capable de fonctionner en **français** et en **anglais**, à travers des approches **extractives** et **abstractive**.

L'application Streamlit : https://text-summarizer-kebjam-ahmed-alex.streamlit.app

## Contenu du dépôt :
* `Presentation_NLP_AS3_2025.pptx` — Présentation PowerPoint du projet.
* `app.py` — Application **Streamlit** pour tester les modèles.
* `NLP_Text_Summarizer.ipynb` — Notebook **Jupyter** regroupant tous les modèles utilisés avec visualisations et comparaisons.
* `requirements.txt` — Dépendances nécessaires à l'exécution de l'application.

## Méthodes utilisées
### Résumé extractif
* **CamemBERT**
* **RoBERTa**
  
### Résumé abstractif
* **BART**
* **T5**
